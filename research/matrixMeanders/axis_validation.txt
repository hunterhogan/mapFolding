Research accelerator
  axis_transfer.cpp mirrors the existing pile-orbit and strip-gap-orbit rules.
  Final transfer layers are streamed in parallel instead of storing their maps;
  this is valid because terminal acceptance is linear in each state's count.
  gap-compact stores the single gap bit's exponent in six bits beside its
  Dyck word. Its transitions and terminal tests use the strip-gap rules.
  Pile indices extend through n=31, pile-wide through 32, full gap through 30,
  compact gap through 28. At n<=32 there are at most 4^31 transfer paths;
  even the doubled sum fits uint64, including parallel partial sums. Gap keys
  use 128 bits, or a checked compact 64-bit representation.
  Completed frontier runs used a 16 GiB address-space limit. The prepared
  n=32 runner allows 28 GiB, but that computation was cancelled before it
  started when the user chose to stop at n=31.
  Larger exploratory Python runs were interrupted to control memory.
  An early C++ n=27 pile attempt was terminated; the smaller allocation
  strategy completed its replacement. Aborted runs produced no accepted terms.

Reproduction, from the repository root
  source .venv/bin/activate
  g++ -O3 -march=native -std=c++20 -fopenmp research/matrixMeanders/axis_transfer.cpp -o /tmp/axis_transfer
  python -m research.matrixMeanders.validate_axis pile 26 27 --cpp /tmp/axis_transfer
  python -m research.matrixMeanders.validate_axis gap-compact 26 27 --cpp /tmp/axis_transfer
  python -m research.matrixMeanders.validate_axis matrixAxisStripGapOrbit 23

  The runner appends candidates and comparisons to axis_validation.jsonl.
  It checks expected counts when present and exact divisibility. --save writes
  newly computed terms immediately using updateValuesKnown.
  Runtime and peak resident memory are recorded per run. Small C++ runs can
  inherit the Python parent's resident-memory high-water mark across exec.

Identities used for A077055
  Even n >= 2: (A005316(n) + A005316(n/2)) / 2.
  Odd n >= 3: (A005316(n) + 2*A223096((n-1)/2)) / 4.
  n=1 is a special base case and is not covered by the odd identity.
