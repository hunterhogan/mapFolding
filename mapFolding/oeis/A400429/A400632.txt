%N Number of semi-meanders with n crossings and winding number n-8, for n >= 8.
%C A semi-meander is a semi-infinite, self-avoiding, directed curve that crosses a line one or more times.
%C The winding number of a semi-meander is the hypothetical minimum number of self-crossings that would be created if a ray were to start at the source of the semi-infinite directed curve and extend to infinity without crossing the line.
%C The maximum winding number of a semi-meander with n crossings is n-2. Thus a(n) counts semi-meanders whose winding number is 6 less than the maximum.
%C Equivalent to a closed curve (a loop) transversely crossing a ray, considered up to continuous deformation fixing the ray, with a winding number equal to the number of crossings that would be created if the fixed end of the ray were extended to form a line.
%C Analogized to a river (a semi-meander, meander, or loop) crossing a road (a ray, line, or line segment).
%C The fourth diagonal of A400429, reading diagonals from the maximal-winding edge.
%H Philippe Di Francesco, Olivier Golinelli and Emmanuel Guitter, <a href="https://arxiv.org/abs/hep-th/9607039">Meanders: A Direct Enumeration Approach</a>, arXiv:hep-th/9607039, 1996 (preprint).
%H Philippe Di Francesco, Olivier Golinelli and Emmanuel Guitter, <a href="https://doi.org/10.1016/S0550-3213(96)00505-6">Meanders: A Direct Enumeration Approach</a>, Nuclear Physics B 482 (1996), no. 3, 497-535.

%F a(n) = T(n,floor(n/2)-3), where T is the triangle A400429.
%F More generally, if D_j is the j-th diagonal of A400429, then 2*j is its least index.
%F For this sequence, j = 4 and 2*j = 8.
%F D_j(2*j) = a(8) = A005315(j) = A005316(2*j-1).
%F D_j(2*j+1) = a(9) = A005315(j+1) = A005316(2*j+1) = D_{j+1}(2*j+2) = A400633(10).
%F a(n) = P(n) + (-1)^n*E(n) + C_3(n) + R_8(n), for n >= 8.
%F P(n) = (294*n^6 - 60*n^5 - 3895*n^4 - 232300*n^3 - 326739*n^2 + 16955410*n - 48570245)/138240; E(n) = (-5*n^4 + 44*n^3 - 289*n^2 + 358*n + 4473)/3072.
%F C_3(n) = (4/27)*(n-2), 4/9, or -(4/27)*(n+1), according as n mod 3 is 0, 1, or 2.
%F R_8(n) = r(n mod 8)/16, where r(0),...,r(7) = 3,-3,5,-1,-5,5,-3,-1.
